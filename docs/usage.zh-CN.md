# 操作说明

[English](usage.md) | [简体中文](usage.zh-CN.md)

## 书库与文件

使用 FAT32 microSD 卡。把文件复制到卡上并安全弹出，再插入阅读器；AP 网页也可以传书。书库统一列出文件，每屏 22 行，首屏包含一行设置入口及 21 本书，最多 256 本。当前没有文件夹导航或网页文件夹管理。

| 格式 | 单文件上限 | 说明 |
|---|---|---|
| EPUB | 64 MiB | 提取后的正文 ≤4 MiB；也支持解包的 `.epub` 目录 |
| TXT | 4 MiB | UTF-8 |
| `.md` / `.markdown` | 1 MiB | UTF-8；格式与公式范围见 [Markdown](markdown.zh-CN.md) |

扩展名不区分大小写。书籍各自记住阅读位置；EPUB 首次打开或版式变更时先显示阅读位置附近的页面，再继续分页，未完成时总页数尚未确定。有效缓存可直接读取原位置附近的正文；渐进分页检查点帮助中断后续排。源文件仍须验证，首次解压也仍有开销。换文件或改路径可能影响旧进度匹配。请保留 SD 卡文件与 NVS，不要为升级格式化卡或擦除整片 Flash。

## 按键

| 场景 | A | B | 短按 A+B |
|---|---|---|---|
| 书库 | 上一本；双击上一屏；长按连续移动 | 下一本；双击下一屏；长按连续移动 | 打开选中项 |
| 阅读 | 上一页；长按连续翻页 | 下一页；长按连续翻页 | 返回书库 |
| 网络设置 | 循环 N → A → U → 关闭 | 切换 R（180°） | 返回书库 |

书库同键两次松开的间隔默认不超过 200 ms 时判为双击翻整屏，超过则按两个单击处理；单击最多等待配置的双击窗口（默认 200 ms） 以区分双击。长按约 600 ms 后开始连续移动。加载或刷新期间的导航操作会丢弃，松开按键后再接受新的操作；底边图标表示忙碌状态。

R 会保存显示方向。翻转后书库与阅读页的 A/B 导航交换，设置页仍保持原物理按键对应；N/A/U 保持同一排，R 位于按键侧。A+B 与电源键不变。

## 中文排版

连续标点压缩和中西文间距默认开启，可在热点网页的 Advanced typography 中调整；设备端没有单独设置页。根据字形实际空白压缩支持的相邻标点，并在相邻汉字与英文字母/数字之间留出少量间距。显式空格不叠加间距；Markdown 代码和公式不参与这两项调整。

## 热点传书与配网

1. 在书库选中首行设置入口，短按 A+B 进入，再用 A 切到热点模式 A。
2. 手机扫描屏幕上的 Wi-Fi 二维码。每次进入 A 都生成新的 SSID 和密码，最多连接一个客户端。
3. 连接成功后，屏幕上的同一个二维码自动变为网页地址。再次扫码打开页面，选择一本书并上传。
4. 页面显示成功后，返回书库打开文件。上传保留中文文件名；同名文件另存，不覆盖已有书。

支持的浏览器默认在手机本地预处理 EPUB，再上传原书和配套内容文件。
这可以减少设备首次导入的解压工作；设备仍负责校验与分页。失败后可以
只上传原书。详见 [EPUB preparation](prepared-content.zh-CN.md)。

屏幕始终保留热点 SSID 和密码；手机断开后，二维码回到连接热点的状态。手机可能提示热点没有互联网，请保持连接。

传输分块进行，只有完整提交后才加入书库。同一会话中的丢响应会自动有限重试。若仍提示失败，请先查看网页书目再重试；不要假定关闭网页、断开热点或设备重启后仍能续传。未完成的传输会清理，已有书籍不受影响。

在网页的 Home Wi-Fi 输入家庭网络名称与密码并保存，再切到 N 模式连接。保存失败不会改写旧配置；密码不会回显或写入日志。热点凭据只保留在当前会话，家庭 Wi-Fi 凭据保存在 NVS（明文）。

AP 在 5 分钟无操作后关闭。后台书目轮询不续期；传输只要持续取得进展就保持活动，45 秒无进展会取消。网页仅在本地 AP 内网提供 HTTP，没有 TLS；二维码内的会话凭据仅在当前热点有效。

## N / A / U

- **N**：连接已保存的家庭 Wi-Fi，开启配对的内网投递接口。SSID、连接状态和 IP 下方显示配对二维码，或当前传输的类型、名称和进度。连接中断后给予 20 秒连接窗口；超时关闭无线电，需要再次进入 N 才重试。
- **A**：临时热点、网页传书与家庭 Wi-Fi 配置。
- **U**：通过原生 USB 向电脑提供 SD 卡。进入前保存进度并关闭设备端文件句柄；此时无法同时阅读或通过网络写卡。完成导书后必须在电脑上安全弹出，再返回书库。只拔线、串口关闭、总线重置或等待一段时间都不等同于安全弹出。

未激活项带 `¬`。离开设置页即关闭网络；U 持有卡时须先安全弹出。重启回到设置时 N/A/U 均未激活。接着 USB 不会自动开启网络。阅读设置与关机图片管理仅在 A 热点网页提供。

N 的发送端使用 [LAN client](lan-protocol.zh-CN.md)，AI 可使用配套的
[delivery skill](skills/paperdiy-delivery/SKILL.md)。首次配对需要屏幕上
有效期为 5 分钟的一次性二维码；之后固定验证该设备证书。普通文件存入 SD 卡的
`Books` 目录，不会覆盖同名书。Push 是书库中的一条固定记录，最多 16 KiB UTF-8 Markdown，支持
已有公式语法；新内容覆盖旧内容，历史由发送端有界归档，设备不累计新书。
关闭 N 后设备不收取内容；发送端保留有限队列，重新开启 N 后可执行同步。
投递成功不会自动打开书籍或改变正在阅读的位置。

## 日文与 EPUB 对象

声明 `vertical-rl` 的受支持 EPUB 内容使用从上到下、从右到左的竖排；
语言标记本身不会强制把横排日文旋转。支持有限的注音、两位数字纵中横，
以及部分 MathML 和简单表格。复杂 CSS、嵌套表格或超出支持范围的对象保留
可读文本回退；字体与兼容范围见 [EPUB typesetting](epub-typesetting.zh-CN.md)。

## 关机、开机与电量

同时按住 A+B 至少 2 秒，看到关机画面后再松开。关机先保存位置；如果提示保存失败，仍保持开机，重试即可。

开机恢复关机前的阅读页、书库位置或设置页；首次没有记录时进入书库。阅读恢复的是保存的文本位置，版式改变后页码可能不同。公开固件没有私人关机图；私人构建可通过仓库外的 `PAPERDIY_SHUTDOWN_HEADER` 提供。

书库显示电池状态，底边图标表示设备状态。空闲时按条件休眠，首次按键应直接执行操作；网络工作期间暂停手动轻睡眠。充电指示灯由充电状态决定。功耗设计与验证范围见 [power.md](power.zh-CN.md)，实际电流仍需仪器测量。

## 网页设置

所有控件使用英文标签。在 A 热点网页中打开设置；阅读器不增加设置书籍。需明确保存，设置可离线保留。

| 控件 | 选项 / 默认值 |
| --- | --- |
| Reading preset | Compact：原生 24 px、行距 34 px、左右边距 18/24 px；Standard（默认）：28/40 px、24/30 px；Relaxed：28/46 px、36/42 px |
| Automatic English hyphenation | 默认开启；用于文档支持英文断字的部分 |
| Alignment | Justified（两端对齐，默认）/ Left aligned（左对齐） |
| Compress adjacent Chinese punctuation | 默认开启，位于 Advanced typography |
| Chinese–Latin spacing | Off / Compact（2 px）/ Standard（4 px，默认） |
| Double-click interval | 100–400 ms，默认 200 ms；按两次松开的间隔计算 |
| Screen refresh | Clarity / Balanced（默认）/ Less flashing |
| Sleep background ink | 0–100%，默认 50%；用单色有序抖动近似中间灰度 |

阅读预设影响正文，不改变界面标签或原生 24 px 代码字库。数学保留原生 28/20/14 px。下次打开书籍时应用排版变化，围绕保存的原文位置重新分页，不以旧页码定位。Balanced 允许连续 10 次阅读局刷，Clarity 为 4 次，Less flashing 为 24 次；场景切换仍完整刷新。

在 Sleep image 上传不超过 12 MiB 的 PNG、JPEG 或 WebP。浏览器在本地转换为有界单色遮罩并预览；白色区域透出调暗后的页面。图片保持比例、不放大，适配 540×960，右下对齐。自定义遮罩存于 SD 卡，不包含在公开源码或固件中。Remove image 禁用叠图，并在 SD 可用时移除两个自定义上传槽。Use firmware default 恢复编译时回退图（私人构建为私人图，公开构建无图）。缺失或无效自定义图也使用该回退；书籍和阅读记录不受影响。
