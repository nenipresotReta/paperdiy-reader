# v0.3.0 — Chinese typography and Markdown math

[English](v0.3.0.md) | [简体中文](v0.3.0.zh-CN.md)

- Offline Markdown reading with headings, lists, quotes, code and a TeX subset including fractions, roots, scripts and matrices. Unsupported formulas retain their complete source.
- Chinese punctuation compression and Chinese–Latin spacing are fixed on in this release. Code uses actual glyph advances and preserves indentation at first lines and page boundaries.
- AP web uploads and home Wi-Fi setup; the same QR changes from Wi-Fi connection to the web page after connection.
- A dense library, rotated settings layout and partial-refresh improvements; library double-click interval set to 200 ms.
- Reflow and cache restoration retain exact source positions; fewer duplicate battery refreshes and Markdown glyph queries.

In this historical release, the library exposes only network and rotation settings. N connects to saved Wi-Fi; U is a placeholder without USB storage. Markdown math is a bounded TeX subset, without full TeX, MathML or EPUB CSS.

Upgrade only application partition `0x10000`, preserving NVS, SD files and their paths. The first open may rebuild old caches. Page numbers can change; progress resumes from source positions. Public firmware contains no personal shutdown artwork, books, reading records, Wi-Fi configuration or diagnostic commands.

See [upgrade](../upgrading.md), [operation](../usage.md) and [Markdown scope](../markdown.md).
