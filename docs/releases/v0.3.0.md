# v0.3.0 — 中文排版与 Markdown 数学阅读

- Markdown 离线阅读，支持标题、列表、引用、代码，以及分式、根式、上下标、矩阵等 TeX 子集。无法支持的公式保留完整原文。
- 中文连续标点压缩和中西文间距固定开启；代码使用实际字宽，保留首行与跨页缩进。
- 热点网页传书、家庭 Wi-Fi 配置；同一个二维码在连接热点后切换到网页入口。
- 密集书库、翻转设置布局和局部刷新改进；书库双击判定窗口设为 200 ms。
- 重新分页和缓存恢复保留精确原文位置；减少重复电量刷新与 Markdown 字形查询。

书库只保留网络与方向设置。N 连接已保存的 Wi-Fi；U 仍为占位，尚不提供 USB 存储。Markdown 数学支持有界 TeX 子集，不支持完整 TeX、MathML 或 EPUB CSS。

升级只写应用分区 `0x10000`，保留 NVS、SD 文件及原路径。第一次打开旧书可能重建缓存；页码可能变化，阅读位置按原文恢复。公开固件不包含个人关机图、书籍、阅读记录、Wi-Fi 配置或诊断命令。

详见[升级说明](../upgrading.md)、[操作说明](../usage.md)与 [Markdown 范围](../markdown.md)。
