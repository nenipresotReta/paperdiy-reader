历史源码/研究快照。下方原型状态和构建数据描述当时基线，当前实现及验收见[架构报告](architecture-and-implementation.md)。

基线：变更前源码。本轮优先减少等待、无效刷新并保持阅读位置，不新增设置页、后台网络服务、默认排版或硬件功耗策略。以下三项小改动已集成和源码测试，本轮为源码级结果，不代表设备验收。

## 已集成改动

### 保留精确阅读锚点

版式变化后恢复偏移可能落在页面内部。此前打开或立即关机会把页首覆盖写回该精确位置；反复重排可在没有翻页时不断向前挪书签。现在保留原文锚点、内容键和包含它的页面，只有实际翻页才采用新页首。验证通过的缓存也发布同一锚点，NVS 键、书籍和缓存版式 ID 均不变。

新增精确偏移断言在基线上失败。回归覆盖当前/旧键、上下文迁移、缓存命中、八次交替 Markdown/普通布局且无额外写入、真实翻页、持久化失败及重试。诊断 `offset` 仍为页首，`anchor_offset` 另报精确位置；关机报告实际保存偏移。

### 只刷新变化的电池像素

电池内部宽 18 像素，86%、87%、88% 填充相同，充电状态没有单独标记。直接比较百分比/充电状态会向面板重复发送同图。UI 现在比较填充宽度，并只绘制一次已采样数值；采样间隔及最后放电历史不变。

真实 UI 的确定性主机轨迹覆盖两个方向、未知值、充电变化、抖动及完整放电序列，结果如下：

| 观察 | 基线 | 候选 |
| --- | ---: | ---: |
| 显示请求 | 427 | 49 |
| 实际电池像素变化 | 49 | 49 |
| 高质量刷新请求 | 10 | 0 |
| 电池像素轨迹哈希 | f4da230e0c0796fb | f4da230e0c0796fb |

该轨迹证明移除了冗余软件/面板请求，不是电流、续航或可见残影测量。固定 M5GFX 面板 worker 对已接受但图像未变的 fast 请求仍做工作；不发请求也避免消耗应用周期性质量刷新额度。没有修改波形或刷新节奏。

### 缓存 Markdown ASCII 度量

准备阶段缓存 128 个 ASCII 字符的原生正文/代码 advance 和正文字形存在性，固定 1152 字节。重复布局查缓存；非 ASCII、样式、数学及绘制仍走原路径。

主机测量条件：macOS arm64、Apple Clang 21、`-O2`，完整分页三次取中位数；生产字库/布局代码，原创合成文档。

| 文档 | 页数 | 基线分页 | 候选分页 |
| --- | ---: | ---: | ---: |
| 1,046,294 B Markdown 正文 | 1525 | 199.24 ms | 43.71 ms |
| 528,080 B Markdown，600 个公式 | 808 | 129.15 ms | 48.72 ms |

约为主机 CPU 4.56×、2.65× 改进，不预测设备开书耗时。EPUB/TXT 已缓存 ASCII，不受影响。所有基准页偏移哈希一致。原生字体回归还固定混合正文/代码/斜体/粗体/链接/CJK/希腊文/数学的两页偏移 `[0, 807]` 与完整帧缓冲哈希 `5d7e6107fc773c9a`。

## 当时仍保留为原型的结果

**EPUB 语义能力记录。** 独立原型保留 ruby 角色、单元格边界及范围，并标记 MathML 或省略对象需要专用渲染。它刻意保持现有提取文本，因为分式或相邻单元格否则可能变成含糊字符串。元数据收集完成不等于忠实渲染。

当时原型通过 85 个原有 EPUB 用例、57 次字节相等比较、22 个新增合成文档和四类预算/分配失败。记录从 24 增至 28 字节，可选 8192 条 arena 增加 32 KiB。当时尚未合并或启用；简单 ruby/表格还需契约，MathML 树、替代内容、图像资源和 CSS 未实现。这些区别依据 HTML [ruby](https://html.spec.whatwg.org/multipage/text-level-semantics.html#the-ruby-element)、[表格](https://html.spec.whatwg.org/multipage/tables.html#attributes-common-to-td-and-th-elements)和 EPUB [嵌入 MathML](https://www.w3.org/TR/epub-33/#sec-xhtml-mathml) 模型。

**增量分页。** 独立的一页/四页预算原型最终得到同一完整索引。它能减少开头附近页面的前置工作，但 90% 的保存位置仍须处理大部分前缀。集成需明确未知页数、完整缓存发布规则及应用循环让步，且不重放过期按键；单纯 `delay()` 不等于该设计。

## 当时的后续顺序

1. 在保留完整性下减少无效 SD 验证。缓存命中仍读全源，64 MiB 合成源案例需读 67,108,864 源字节加 4,210,844 缓存字节。按最大 4 MHz SPI，仅串行位传输就约 142.6 秒；这是最大尺寸案例的计算下界，不是用户书籍实测。下方后续已在哈希前拒绝不同大小/mtime，匹配时仍查摘要；不能为提速丢掉同大小同时间替换检测。
2. 先证明挂载代次撤销，再考虑会话内已验证指纹。重启、拔卡/重挂、介质/读错误、所有写入、未来 USB MSC 切换都须撤销，仅缓存时间戳不够。之后再评估延迟缓存写入/部分分页。
3. 以稳定原文锚点和有界内存回退连接 EPUB 语义块：标题与正文、本地语言断行，再窄范围 ruby/表格/数学。空白处理继续独立 A/B。
4. 单独调查 PMIC 轮询。清醒应用可能约每秒 100 次，电池轻睡眠维护已约每秒一次。不能整体降低同时服务按钮的 `M5.update()`，也不能未测电源键/USB 唤醒就延长睡眠。
## 验证边界

合并源码通过 23 项 ASan/UBSan CTest 和固定 ESP32-S3 固件构建：Flash 3,644,893 字节、静态 RAM 56,060 字节。

后续诊断构建通过 24/24，读探针以 C++11 无异常编译，使用 Flash 3,644,889 字节、静态 RAM 56,060 字节。

合成夹具覆盖 706 字节混合数学笔记（源边界 0/540/706）、131,054 字节 Markdown 夹具分页为 213 页。这些是内存夹具结果，不是 SD 开书延迟或设备速度比较。

后续加入源 stamp 拒绝预筛选，以及可选、有界 SD/合成 Markdown 诊断。回归覆盖主/备缓存、源缺失、同大小同时间替换、验证阶段变化、保存失败及精确锚点。诊断构建禁用 DEVICE_TESTS/NETWORK_TESTS，保留本地 DIAGNOSTICS。公开回归位于 `reader_integration`、`cache_adapter`、`ui_simulation`。

公开证据不包含私人书籍、阅读记录、设备图片、凭据或 NVS 内容；设备专属观察和操作日志已省略。
